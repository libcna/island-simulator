# Asset Licenses and Attribution

## Project-generated and original content

Monkey fur source: built-in ImageGen output, preserved at
`assets/art-studies/monkey-fur-albedo-v1.png` with the exact project-authored prompt in
`assets/art-studies/monkey-fur-albedo-v1-prompt.txt`. **AI-generated monkey-fur study**:
not a photograph or scan; project artwork with no declared repository license and no
CC0 or exclusive-copyright claim. Original 1254-square PNG retained unchanged; build
preparation reduces it to 512 square, runtime uploads ten mip levels. Interior-only
rest-mesh UV windows avoid relying on unverified seamless tiling. Applied to monkey
body/head/limbs/tail, not the bare face or eyes. See `docs/monkey-fur-material.md`.

Runtime now selects the second source `assets/art-studies/monkey-fur-albedo-v2.png`,
generated with built-in ImageGen from `assets/art-studies/monkey-fur-albedo-v2-prompt.txt`.
The original output is preserved unchanged; v1 remains historical evidence. The same
AI-generated project-artwork attribution and license limitations above apply to v2.
No external references were supplied. Angular interior UV mapping replaces the side-
compressing projection; this does not assert that either source tiles seamlessly.

The island field, render meshes, vertex colours, animated ocean and sky, vegetation/prop geometry,
placement data, touch graphics, and developer bitmap font currently present in this repository are
generated from original project code and contain no external asset data. The Android launcher icon
is original project artwork stored directly as vector XML rather than generated at runtime.

External assets must be added here before they enter a runtime build. Each entry must include a
stable source, author where applicable, exact license, modifications, and in-game use. Downloaded
archives and remote URLs alone are not reproducible provenance.

The canopy-associated forest-floor colonies are original `JungleLayout` placement
code using the existing procedural jungle assets above. They introduce no external
source, texture or separate model license. Composition and provenance details are
in `docs/forest-floor-colonies.md`.

`ForestFloorSampling`, `ForestFloorPixels` and `ForestFloorMaterial` are original project code.
The game packages a pixel-equivalent 512-square build derivative of v1 as
`Content/terrain/forest-floor.png`, constructs ten opaque mip levels at runtime,
and samples bounded interior windows. See `docs/prepared-materials.md` for reduction evidence.
The source PNG is unchanged. The rejected v2 study remains source evidence and is not packaged.
See `docs/forest-floor-material-review.md` for exact inputs, limitations and reproducible commands.

`assets/manifest.json` maps every row above to its owning procedural source files or hashed original
project files and is the machine-readable gate for future external files. Run
`python3 tools/validate_assets.py` after any content or attribution change. See
`docs/asset-pipeline.md` for the project/external-file fields, hashing rules, and intake procedure.
