# Asset Licenses and Attribution

## Project-generated content

The island field, render meshes, vertex colours, animated ocean, palm/grass geometry, and placement
data currently present in this repository are generated from original project code and contain no
external asset data.

| Asset | Source | Author | License | Modifications | Use |
|---|---|---|---|---|---|
| Procedural island field | Generated by `IslandTerrain` | island-simulator contributors | Original project content; repository license not yet declared | Runtime deterministic generation | Island terrain and seabed |
| Procedural animated ocean | Generated by `OceanRenderer` | island-simulator contributors | Original project content; repository license not yet declared | Runtime deterministic grid and portable shader animation | Tropical ocean |
| Procedural palms | Generated by `VegetationLayout` and `PalmRenderer` | island-simulator contributors | Original project content; repository license not yet declared | Deterministic placement plus four runtime-generated trunk/frond mesh variants | Island vegetation |
| Procedural mesh grass | Generated by `GrassLayout` and `GrassRenderer` | island-simulator contributors | Original project content; repository license not yet declared | Deterministic placement plus runtime-generated near/far blade clusters and shader wind | Ground vegetation |

External assets must be added here before they enter a runtime build. Each entry must include a
stable source, author where applicable, exact license, modifications, and in-game use. Downloaded
archives and remote URLs alone are not reproducible provenance.
