# Canopy palette separation — 2026-10-16

## Scope

The current overview, jungle and clearing-edge audit found that the island's terrain, water and
fixed daylight were coherent, but the structurally distinct broadleaf forms still merged into one
saturated middle-distance green band. This pass changes only vertex colours generated by the
existing canopy mesh builder. It does not change tree placement, geometry, buffers, fixed-sun
occluders, culling bounds, LOD thresholds, wind, shadows or draw calls.

The eight natural tree forms now span deep emerald, fresh green, olive, blue-green and warm-green
families; the mangrove keeps a darker salt-shaded green. Four bounded lobe blends add subtle warm,
cool and muted variation inside each crown. Existing deterministic leaf-level pigment and daylight
remain layered on top, so the result separates neighbouring masses without rainbow patching.
