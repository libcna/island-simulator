## Finding and correction

The walking-height views selected repeated trunk mass as the highest-impact scale defect. Eight
different crown structures still stood on the same linear 43-to-23 cm shaft and therefore read as
copies on poles. `CanopyTrunkRadius` now gives the nine natural/mangrove forms deterministic taper
families while retaining the exact shared root and crown radii. The forms only become fuller than
the old linear shaft between those contacts, so collision clearance and monkey reach cannot be
reduced. The existing near/far meshes, instance count, buffers and draw calls are unchanged.

Core coverage requires measurable mid-shaft variation, monotone bounded taper, valid near/far
surface normals, reachable attachment paths for every form and a completed ordinary climbing
simulation. Accepted post-fix native views are `20261015T120043.010355Z-jungle`,
`20261015T120047.265616Z-east` and `20261015T120051.517078Z-overview`. The final current-binary
jungle confirmation is `20261015T120808.107810Z-jungle` (275 colour bins, 46.47 luminance
deviation, 213.79 spatial contrast).
